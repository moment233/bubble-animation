# 🫧 React Bubble Animation with Depth of Field

React/Next.js 版本的气泡上升动画，带有真实的景深模糊效果。

## ✨ 功能特性

- 🎈 **15个气泡**持续上升并循环重生
- 📏 **多样化尺寸**（0.15-0.6，包含小气泡）
- 🔄 **Z轴运动**（-12到12范围内前后摆动）
- 🌫️ **真实景深模糊**（后处理效果）
- 🎛️ **实时控制面板**（焦点、光圈、模糊强度）
- 📱 **移动端自适应**（自动调整光圈参数）
- ✨ **彩虹色薄膜干涉**（物理真实的颜色）
- 🎨 **SimplexNoise 顶点变形**（自然的气泡抖动）

## 🚀 快速开始

```bash
# 安装依赖

# 启动开发服务器
```

## 🎯 景深参数说明

### 焦点距离 (Focus)
- **范围**: 0-25
- **说明**: 相机到焦平面的距离
- **相机位置**: Z = 10
- **焦点Z位置** = 10 - focus
- **示例**: focus = 10 时，焦点在 Z = 0（场景中心）

### 光圈大小 (Aperture)
- **范围**: 0.00001-0.005
- **说明**: 光圈越大，景深越浅，模糊效果越强
- **类比**: 相机的大光圈（f/1.4）vs 小光圈（f/16）
- **移动端**: 自动增强 1.5x

### 最大模糊 (Max Blur)
- **范围**: 0.001-0.1
- **说明**: 限制模糊的最大程度，防止过度模糊

## 📐 场景参数

- **相机位置**: (0, 0, 10)
- **气泡数量**: 15个
- **气泡尺寸**: 0.15-0.6（随机）
- **上升速度**: 0.3-0.8 units/sec
- **X轴范围**: -4 到 4
- **Z轴范围**: -12 到 12（含运动）
- **顶部边界**: Y = 6

## 🎨 Shader 特性

- **薄膜干涉**: 物理真实的彩虹色计算
- **菲涅耳效果**: 边缘更亮
- **环境反射**: HDR 环境贴图
- **折射**: 光线穿过气泡
- **优化**: 移除噪声避免黑点闪烁

## 📱 设备适配

应用会自动检测设备类型并调整参数：
- **检测屏幕宽度** < 768 为移动端
- **移动端光圈** 自动增强 1.5x
- **像素比** 限制为最大 2
- **控制台输出** 设备信息
