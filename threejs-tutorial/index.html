Three.js 从入门到气泡

15步实战教程 - 从零开始学习 Three.js 和着色器编程

01

Hello Three.js - 静态立方体

Scene 场景 Camera 相机 Renderer 渲染器

学习 Three.js 的三个核心要素：场景（Scene）、相机（Camera）和渲染器（Renderer）。就像拍电影一样，场景是舞台，相机决定拍摄角度，渲染器负责把画面输出到屏幕。

JavaScript
// 1. 创建场景（舞台）
const scene = new THREE.Scene();

// 2. 创建相机（观众视角）
const camera = new THREE.PerspectiveCamera(
  75,                           // 视野角度
  400 / 400,                    // 宽高比
  0.1,                          // 最近可见距离
  1000                          // 最远可见距离
);
camera.position.z = 5;          // 相机向后退5个单位

// 3. 创建渲染器（摄像机）
const renderer = new THREE.WebGLRenderer({ 
  antialias: true               // 抗锯齿
});
renderer.setSize(400, 400);

// 4. 创建立方体
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ 
  color: 0x00d9ff               // 青色
});
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);                // 添加到场景

// 5. 渲染一次
renderer.render(scene, camera);
💡 核心概念
  • Scene : 3D 世界的容器，所有物体都要添加到场景中
  • PerspectiveCamera : 透视相机，模拟人眼视角（近大远小）
  • WebGLRenderer : 使用 WebGL 技术渲染 3D 图形
  • Mesh : 几何体 + 材质 = 可见的 3D 物体

02

添加动画循环 - 旋转立方体

requestAnimationFrame Animation Loop 动画循环

使用 requestAnimationFrame 创建动画循环，让立方体持续旋转。这个函数会在浏览器每次重绘前调用，通常是 60 次/秒（60 FPS）。

JavaScript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(400, 400);

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x00d9ff });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 动画循环函数
function animate() {
  requestAnimationFrame(animate);  // 递归调用，持续执行
  
  // 每帧旋转一点
  cube.rotation.x += 0.01;         // 绕 X 轴旋转
  cube.rotation.y += 0.01;         // 绕 Y 轴旋转
  
  renderer.render(scene, camera);  // 重新渲染
}

animate();  // 启动动画
💡 核心概念
  • requestAnimationFrame : 浏览器提供的动画 API，比 setInterval 更高效
  • rotation : 旋转属性，单位是弧度（不是角度）
  • 递归调用 : animate 函数调用自己，形成循环

从立方体到球体 - 不同几何体

SphereGeometry Geometry Parameters

Three.js 提供了多种内置几何体。球体由参数控制：半径、水平分段数、垂直分段数。分段数越大，球体越圆滑，但性能消耗也越大。

JavaScript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(400, 400);

// 创建球体几何体
const geometry = new THREE.SphereGeometry(
  1,      // 半径
  32,     // 水平分段数（经线数量）
  32      // 垂直分段数（纬线数量）
);

const material = new THREE.MeshBasicMaterial({ 
  color: 0x00d9ff,
  wireframe: false  // 设为 true 可看到网格结构
});

const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);

function animate() {
  requestAnimationFrame(animate);
  sphere.rotation.y += 0.01;  // 只绕 Y 轴旋转
  renderer.render(scene, camera);
}

animate();
🎯 尝试修改
  • 修改分段数为 8，看看球体变得棱角分明
  • 设置 wireframe: true 查看球体的网格结构
  • 调整半径参数，改变球体大小

透明材质基础

Transparent Opacity

通过设置材质的 transparent 和 opacity 属性，可以让物体变得半透明。这是实现气泡效果的基础。

JavaScript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ 
  antialias: true,
  alpha: true  // 允许透明背景
});
renderer.setSize(400, 400);

const geometry = new THREE.SphereGeometry(1, 32, 32);
const material = new THREE.MeshBasicMaterial({ 
  color: 0x00d9ff,
  transparent: true,  // 启用透明
  opacity: 0.6        // 透明度（0=完全透明，1=不透明）
});

const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);

function animate() {
  requestAnimationFrame(animate);
  sphere.rotation.y += 0.01;
  renderer.render(scene, camera);
}

animate();
💡 透明渲染原理
  • transparent: true 必须设置，否则 opacity 无效
  • opacity 范围 0.0 ~ 1.0，数值越小越透明
  • 透明物体的渲染顺序很重要，可能影响显示效果

05

简单动画 - 垂直浮动

Math.sin() Position Animation

使用 Math.sin() 三角函数创建周期性运动。正弦函数产生平滑的波动效果，非常适合模拟自然的漂浮运动。

JavaScript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ 
  antialias: true,
  alpha: true
});
renderer.setSize(400, 400);

const geometry = new THREE.SphereGeometry(1, 32, 32);
const material = new THREE.MeshBasicMaterial({ 
  color: 0x00d9ff,
  transparent: true,
  opacity: 0.6
});

const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);

let time = 0;

function animate() {
  requestAnimationFrame(animate);
  
  time += 0.02;  // 时间增量
  
  // 使用正弦函数产生上下浮动
  // Math.sin() 返回 -1 到 1 之间的值
  sphere.position.y = Math.sin(time) * 1.5;
  
  sphere.rotation.y += 0.01;
  renderer.render(scene, camera);
}

animate();
💡 正弦函数动画
  • Math.sin(time) : 返回 -1 到 1 的周期性值
  • 乘以 1.5 是振幅，控制运动范围
  • time += 0.02 控制运动速度，值越大速度越快
  • 正弦曲线创造平滑、自然的加减速效果

06

复合动画 - 水平摇摆

Multi-axis Motion Combined Animation

同时控制多个轴的运动，创造更真实的飘动效果。通过使用不同频率的正弦函数，让运动看起来更自然、不规则。

JavaScript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ 
  antialias: true,
  alpha: true
});
renderer.setSize(400, 400);

const geometry = new THREE.SphereGeometry(1, 32, 32);
const material = new THREE.MeshBasicMaterial({ 
  color: 0x00d9ff,
  transparent: true,
  opacity: 0.6
});

const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);

let time = 0;

function animate() {
  requestAnimationFrame(animate);
  
  time += 0.02;
  
  // 垂直浮动（快速）
  sphere.position.y = Math.sin(time) * 1.5;
  
  // 水平摇摆（慢速，频率不同）
  sphere.position.x = Math.sin(time * 0.7) * 0.8;
  
  sphere.rotation.y += 0.01;
  renderer.render(scene, camera);
}

animate();
🎯 运动组合技巧
  • Y 轴使用 sin(time) ，X 轴使用 sin(time * 0.7)
  • 不同的频率（0.7）避免运动过于规则
  • 不同的振幅（1.5 vs 0.8）创造不对称的运动
  • 可以添加 Z 轴运动，创造 3D 空间的飘动
下一步预告： 进入着色器世界，使用 GLSL 编程 🎨
07

着色器入门 - 纯色着色器

ShaderMaterial GLSL Vertex Shader Fragment Shader

着色器是运行在 GPU 上的程序，用 GLSL 语言编写。分为顶点着色器（处理顶点位置）和片段着色器（处理像素颜色）。这是创建真实气泡效果的关键技术。

JavaScript + GLSL
// 顶点着色器：处理每个顶点
const vertexShader = `
  void main() {
    // 将顶点位置转换到屏幕坐标
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

// 片段着色器：处理每个像素
const fragmentShader = `
  void main() {
    // 设置像素颜色为红色 (R, G, B, A)
    gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0);
  }
`;

const geometry = new THREE.SphereGeometry(1, 32, 32);
const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader
});

const sphere = new THREE.Mesh(geometry, material);
scene.add(sphere);
💡 着色器基础
  • 顶点着色器 : 处理几何体的每个顶点（位置、法向量等）
  • 片段着色器 : 处理每个像素的颜色
  • GLSL : OpenGL Shading Language，类似 C 语言
  • vec4(R, G, B, A) : RGBA 颜色，范围 0.0 ~ 1.0
  • gl_Position 和 gl_FragColor 是必须设置的输出变量

08

着色器变量 - 传递数据

uniform Data Passing

uniform 变量是从 JavaScript 传递到着色器的数据。通过 uniform，我们可以动态控制着色器的行为，比如改变颜色、时间等。

JavaScript + GLSL
const vertexShader = `
  void main() {
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  uniform vec3 uColor;  // 从 JS 接收颜色
  
  void main() {
    gl_FragColor = vec4(uColor, 1.0);
  }
`;

const material = new THREE.ShaderMaterial({
  vertexShader: vertexShader,
  fragmentShader: fragmentShader,
  uniforms: {
    uColor: { value: new THREE.Color(0x00d9ff) }  // 传递颜色
  }
});

// 可以动态修改 uniform 值
// material.uniforms.uColor.value = new THREE.Color(0xff0000);
💡 uniform 变量
  • uniform : 在整个绘制过程中保持不变的全局变量
  • 从 JavaScript 传入，所有顶点和像素共享同一个值
  • 常用于传递：颜色、时间、相机位置、贴图等
  • 命名约定：通常以 u 开头，如 uColor、uTime
下一步预告： 使用 varying 变量，创建渐变效果 🌈
09

顶点数据 - 位置渐变

varying Gradient

varying 变量用于从顶点着色器传递数据到片段着色器。数据会在顶点之间自动插值，创造平滑的渐变效果。

JavaScript + GLSL
const vertexShader = `
  varying vec3 vPosition;  // 传递给片段着色器
  
  void main() {
    vPosition = position;  // 保存顶点位置
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  varying vec3 vPosition;  // 接收插值后的位置
  
  void main() {
    // 基于 Y 坐标创建蓝到白的渐变
    // normalize: 将 -1~1 映射到 0~1
    float gradient = (vPosition.y + 1.0) * 0.5;
    
    vec3 colorBottom = vec3(0.0, 0.5, 1.0);  // 蓝色
    vec3 colorTop = vec3(1.0, 1.0, 1.0);     // 白色
    
    // 混合颜色
    vec3 finalColor = mix(colorBottom, colorTop, gradient);
    
    gl_FragColor = vec4(finalColor, 1.0);
  }
`;
💡 varying 插值原理
  • varying : 在顶点着色器设置，片段着色器接收
  • GPU 会自动在顶点之间插值，创造平滑过渡
  • mix(a, b, t) : 线性插值函数，t=0 返回 a，t=1 返回 b
  • position.y 的范围是 -1 到 1（球体半径为1）
下一步预告： 学习法向量，理解光照基础 ✨
10

法向量基础 - 可视化法向量

Normal Surface Direction

法向量是垂直于表面的向量，用于计算光照、反射等效果。通过可视化法向量（映射到 RGB 颜色），可以直观理解表面朝向。

JavaScript + GLSL
const vertexShader = `
  varying vec3 vNormal;  // 传递法向量
  
  void main() {
    vNormal = normal;  // normal 是内置变量
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  varying vec3 vNormal;
  
  void main() {
    // 法向量范围 -1~1，映射到 0~1 用作颜色
    vec3 color = vNormal * 0.5 + 0.5;
    
    // X → Red, Y → Green, Z → Blue
    // 右侧=红色，上方=绿色，前方=蓝色
    
    gl_FragColor = vec4(color, 1.0);
  }
`;
💡 法向量概念
  • 法向量 : 垂直于表面的单位向量（长度为1）
  • normal : Three.js 内置变量，每个顶点都有法向量
  • 法向量决定表面朝向，是光照计算的基础
  • 颜色映射：红=右，绿=上，蓝=前（基于坐标轴）
下一步预告： 使用法向量实现菲涅耳效应 🌟
11

菲涅耳效应 - 边缘检测

Fresnel Effect Dot Product

菲涅耳效应：从侧面看物体比从正面看更亮。通过计算视线方向和法向量的夹角，可以检测边缘。这是气泡效果的核心之一。

JavaScript + GLSL
const vertexShader = `
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  void main() {
    vNormal = normalize(normalMatrix * normal);
    vPosition = (modelMatrix * vec4(position, 1.0)).xyz;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const fragmentShader = `
  uniform vec3 uCameraPos;
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  void main() {
    // 视线方向：从表面指向相机
    vec3 viewDirection = normalize(uCameraPos - vPosition);
    
    // 点积：计算法向量和视线的夹角
    // 夹角小（正对）→ 1.0
    // 夹角大（侧面）→ 0.0
    float NdotV = dot(normalize(vNormal), viewDirection);
    
    // 反转：边缘亮，中心暗
    float fresnel = 1.0 - NdotV;
    
    gl_FragColor = vec4(vec3(fresnel), 1.0);
  }
`;
💡 点积（Dot Product）
  • dot(a, b) : 计算两个向量的点积
  • 当向量平行时，点积 = 1（同向）或 -1（反向）
  • 当向量垂直时，点积 = 0
  • NdotV : Normal dot View，法向量与视线的点积
  • 用于判断表面是正对还是侧对相机
下一步预告： 使用 pow 函数增强边缘发光 💫
12

菲涅耳进阶 - 边缘发光

pow Function Edge Glow

使用 pow() 函数调整菲涅耳强度，让边缘发光更明显。指数越大，边缘越锐利；指数越小，过渡越平滑。

JavaScript + GLSL
const fragmentShader = `
  uniform vec3 uCameraPos;
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  void main() {
    vec3 viewDirection = normalize(uCameraPos - vPosition);
    float NdotV = dot(normalize(vNormal), viewDirection);
    
    // 使用 pow 增强边缘效果
    // 指数越大，边缘越窄越亮
    float fresnel = pow(1.0 - NdotV, 2.5);
    
    // 添加颜色
    vec3 glowColor = vec3(0.0, 0.8, 1.0);  // 青色
    vec3 finalColor = glowColor * fresnel;
    
    gl_FragColor = vec4(finalColor, 1.0);
  }
`;
🎯 调整菲涅耳参数
  • pow(x, 1.0) : 线性，过渡平滑
  • pow(x, 2.0) : 二次方，中等强度
  • pow(x, 3.0) : 三次方，边缘锐利
  • pow(x, 5.0) : 五次方，非常锐利的边缘
  • 真实气泡通常使用 1.8 ~ 2.5 之间的指数
下一步预告： 添加薄膜干涉，产生彩虹色 🌈
13

薄膜干涉 - 彩虹色原理

Thin Film Interference Iridescence

薄膜干涉是光波在薄膜两侧反射后相互干涉的现象。不同波长的光干涉程度不同，产生彩虹色。这是气泡最具特色的视觉效果。

JavaScript + GLSL
const fragmentShader = `
  uniform vec3 uCameraPos;
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  vec3 getThinFilmColor(float cosTheta, float thickness) {
    const float PI = 3.14159265359;
    
    // 光程差计算（折射率 1.33）
    float opticalPath = 2.0 * 1.33 * thickness * cosTheta;
    
    // 不同波长的相位（纳米）
    float phaseR = (2.0 * PI * opticalPath) / 650.0;  // 红
    float phaseG = (2.0 * PI * opticalPath) / 550.0;  // 绿
    float phaseB = (2.0 * PI * opticalPath) / 450.0;  // 蓝
    
    // 干涉强度
    float intensityR = 0.5 + 0.5 * cos(phaseR);
    float intensityG = 0.5 + 0.5 * cos(phaseG);
    float intensityB = 0.5 + 0.5 * cos(phaseB);
    
    return vec3(intensityR, intensityG, intensityB);
  }
  
  void main() {
    vec3 viewDirection = normalize(uCameraPos - vPosition);
    float NdotV = dot(normalize(vNormal), viewDirection);
    
    // 薄膜厚度（基于位置变化）
    float thickness = 300.0 + vNormal.y * 200.0;
    
    // 计算干涉颜色
    vec3 iridescence = getThinFilmColor(NdotV, thickness);
    
    // 菲涅耳边缘效果
    float fresnel = pow(1.0 - NdotV, 2.0);
    
    // 混合效果
    vec3 finalColor = iridescence * (0.8 + fresnel * 0.5);
    
    gl_FragColor = vec4(finalColor, 1.0);
  }
`;
💡 薄膜干涉原理
  • 光程差 : 光在薄膜内往返的路径长度差异
  • 相位 : 光波的位置，决定是增强还是减弱
  • 波长 : 红光 650nm，绿光 550nm，蓝光 450nm
  • 干涉 : 相位相同增强（亮），相反减弱（暗）
  • 厚度变化导致不同位置显示不同颜色

14

环境映射 - 反射周围环境

HDR Environment Map Reflection

环境映射让物体能够反射周围环境。我们使用 MeshStandardMaterial 配合 HDR（高动态范围）贴图，可以轻松实现真实的金属反射效果。

JavaScript + GLSL
// 使用 MeshStandardMaterial - 完美支持 PBR 和环境映射
const material = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  metalness: 1.0,      // 完全金属质感（高反射）
  roughness: 0.1,      // 非常光滑（清晰反射）
  envMapIntensity: 1.5 // 环境贴图强度
});

// 加载 HDR 环境贴图
const rgbeLoader = new THREE.RGBELoader();
rgbeLoader.load('./studio_small_08_1k.hdr', (texture) => {
  // 使用 PMREMGenerator 生成预过滤环境贴图
  const pmremGenerator = new THREE.PMREMGenerator(renderer);
  const envMap = pmremGenerator.fromEquirectangular(texture).texture;
  
  // 设置场景环境 - 自动应用到所有 Standard/Physical 材质
  scene.environment = envMap;
  
  // 清理资源
  pmremGenerator.dispose();
  texture.dispose();
});
💡 PBR 材质与环境映射
  • MeshStandardMaterial : 基于物理的渲染（PBR）材质，自动处理环境映射
  • metalness : 金属度（0=非金属，1=金属）- 影响反射程度
  • roughness : 粗糙度（0=光滑，1=粗糙）- 影响反射清晰度
  • PMREMGenerator : 预过滤环境贴图生成器，将 HDR 转换为多级 mipmap

  • HDR 贴图提供真实的光照和反射信息

完整真实气泡 - 综合效果

Complete Effect Fresnel + Thin Film + Reflection Physical Animation

最终步骤！将所有技术组合：菲涅耳效应、薄膜干涉、环境映射、透明度控制，再加上物理动画，创造出逼真的气泡效果。

JavaScript + GLSL（完整着色器）
const vertexShader = `
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  void main() {
    vNormal = normalize(normalMatrix * normal);
    vec4 worldPosition = modelMatrix * vec4(position, 1.0);
    vPosition = worldPosition.xyz;
    gl_Position = projectionMatrix * viewMatrix * worldPosition;
  }
`;

const fragmentShader = `
  uniform vec3 uCameraPos;
  uniform samplerCube envMap;
  varying vec3 vNormal;
  varying vec3 vPosition;
  
  // 薄膜干涉颜色
  vec3 getThinFilmColor(float cosTheta, float thickness) {
    const float PI = 3.14159265359;
    float opticalPath = 2.0 * 1.33 * thickness * cosTheta;
    
    float phaseR = (2.0 * PI * opticalPath) / 650.0;
    float phaseG = (2.0 * PI * opticalPath) / 550.0;
    float phaseB = (2.0 * PI * opticalPath) / 450.0;
    
    vec3 color;
    color.r = pow(0.5 + 0.5 * cos(phaseR), 1.2);
    color.g = pow(0.5 + 0.5 * cos(phaseG), 1.2);
    color.b = pow(0.5 + 0.5 * cos(phaseB), 1.2);
    
    return color;
  }
  
  void main() {
    vec3 viewDirection = normalize(uCameraPos - vPosition);
    vec3 normal = normalize(vNormal);
    float NdotV = abs(dot(normal, viewDirection));
    
    // 1. 菲涅耳效应
    float fresnel = pow(1.0 - NdotV, 1.8);
    
    // 2. 薄膜干涉
    float thickness = 300.0 + vNormal.y * 400.0 + vNormal.x * 150.0;
    vec3 iridescence = getThinFilmColor(NdotV, thickness) * 1.5;
    
    // 3. 环境反射
    vec3 reflected = reflect(-viewDirection, normal);
    vec3 envColor = textureCube(envMap, reflected).rgb;
    
    // 4. 折射
    vec3 refracted = refract(-viewDirection, normal, 1.0 / 1.33);
    vec3 refractColor = textureCube(envMap, refracted).rgb;
    
    // 5. 混合策略
    float edgeMask = smoothstep(0.2, 0.95, fresnel);
    vec3 edgeColor = mix(iridescence, envColor, fresnel * 0.35);
    vec3 centerColor = refractColor * 3.0 + envColor * 0.15;
    
    vec3 finalColor = mix(centerColor, edgeColor, edgeMask);
    
    // 6. 增强饱和度和亮度
    float luminance = dot(finalColor, vec3(0.299, 0.587, 0.114));
    finalColor = mix(vec3(luminance), finalColor, 1.6);
    finalColor *= 1.3;
    finalColor += envColor * 0.08;
    
    // 7. 透明度
    float alpha = edgeMask * 0.95 + (1.0 - edgeMask) * 0.15;
    
    gl_FragColor = vec4(finalColor, alpha);
  }
`;
