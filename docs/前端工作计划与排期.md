一、工作优先级
主线任务：产品业务开发 (P0)
- 核心目标：根据产品需求完成业务功能开发
- 依赖条件：产品需求文档、设计稿、后端接口文档
并行任务：基础设施建设 (P0)
- 核心目标：搭建高效的开发环境和工程体系
- 启动时机：项目启动即开始，贯穿开发全程
次要任务：前端监控 & SEO (P1)
- 核心目标：数据分析能力 + 搜索引擎优化
- 启动时机：产品核心功能完成后

次要任务 1：数据监控体系
监控方案设计
- 选型：Google Analytics / 神策 / 友盟 / Mixpanel
- 监控规范：命名规则、参数标准、触发时机
- 隐私合规：用户同意、数据脱敏
SDK 集成与封装
监控实施
- 通用监控：PV/UV、页面停留时间、跳出率
- 交互监控：按钮点击、表单提交、搜索行为
- 业务监控：核心转化、漏斗分析、用户路径
- 性能监控：页面加载、接口响应、错误率
监控告警
- 错误监控：Sentry 接入
- 性能监控：RUM
- 自定义看板：关键指标可视化
次要任务 2：SEO 优化
技术 SEO
- SSR/SSG 策略：关键页面 SSR，静态内容 SSG
- 动态 Sitemap：自动生成，定期更新
- robots.txt：配置爬虫规则
- 结构化数据：JSON-LD（网站、面包屑、产品等）
性能优化
- Core Web Vitals 指标达标
  - LCP
  - FID
  - CLS
- 图片优化：WebP 、懒加载、响应式
- 代码分割：动态导入、路由级分割
- 资源优化：压缩、CDN、预加载
内容优化
- 语义化 HTML 标签
- 无障碍访问（ARIA、键盘导航）
- 移动端适配与友好性
并行：全面性能优化
- Bundle 体积分析与优化
- 接口性能优化（请求合并、缓存策略）
- 渲染性能优化（虚拟滚动、防抖节流）
- CDN 配置与资源加速

四、技术架构关键点
分层架构
/app                # 路由与页面
/components         # 组件库
  /ui               # 基础 UI 组件
  /business         # 业务组件
/services           # API 调用
/hooks              # 自定义 Hooks
/utils              # 工具函数
/types              # 类型定义
/lib                # 第三方库配置
核心
- SSR/SSG：首屏快速、SEO 友好
- 类型安全：100% TypeScript，自动生成 API 类型
- 组件化：可复用、可测试
- 工程化：代码规范、自动化测试、CI/CD
